揪團日曆

一群人各自標出可以、不行的日子和時段，系統自動算出大家都能約的那一天。按一個按鈕就能部署成你自己的網站，活動名稱、日期範圍、假日和成員都能在網頁上改。

能做什麼

不用再一個一個問「你哪天可以」

每個人花幾分鐘填自己的空檔，合併結果會即時更新，看一眼就知道哪天大家都行、哪天誰卡住。

規則一次填一大片

平日、假日、國定假日、星期幾分別設可以或不行，不用一天一天點。

時段精確到分鐘

24 小時制，可以整批套用，也能長按某一天單獨改。

管理員可以代填

不太會用的成員，管理員先幫他填好，他本人進來還能自己改。

什麼都能改

活動名稱、日期範圍、假日、預設時段、成員名單，都在網頁的「管理」裡改。

一鍵部署

五分鐘做出你自己的揪團網站

按下按鈕後，Cloudflare 會把程式複製到你的 GitHub、在你的帳號建好資料庫並上線。之後你改 GitHub 上的程式，網站也會自動更新。

  1. 按「一鍵部署」

    用這頁最上面的橘色按鈕，登入 Cloudflare，再連結你的 GitHub。

  2. 取名字、設密碼

    專案名稱會變成網址的一部分，例如 book-club。在 ADMIN_PASSWORD 填一組只有你知道的管理員密碼。

  3. 按 Deploy

    資料庫 team-cal 會自動建好，大約一分鐘後拿到網址：book-club.你的子網域.workers.dev。

  4. 設定活動、加成員

    打開網址，按右上角「管理」登入，照下面的案例 1 設定，然後把網址傳給大家。

操作案例

跟著一個讀書會走一遍

以下用「春季讀書會」當例子：六個人要在 2027 年 3 到 6 月找一天聚會。

案例 1 · 管理員開團

阿哲建立活動、加入成員

角色：管理員。用到：右上角「管理」→「活動設定」「管理成員」

  1. 打開網站，按右上角「管理」，輸入部署時設的管理員密碼。
  2. 按「活動設定」：名稱填「春季讀書會」，從 2027-03 到 2027-06，預設時段 14:00–18:00。
  3. 按「＋ 台灣 2027 國定假日」，清明、勞動節、端午會自動填進放假日。也可以一行一天自己加，例如 2027-05-22 社區活動。
  4. 按「儲存設定」，回到「管理成員」，輸入名字、選顏色，把六個人加進去。
  5. 把網址貼到群組，請大家點「我是 某某」開始填。

案例 2 · 成員填寫

小美：平日晚上不行，週末可以

角色：一般成員。四個步驟：規則 → 時段 → 微調 → 完成

  1. 點「我是 小美」，第一次進來可以設個密碼，別人就不能改她的。
  2. 規則：平日按「不行」，假日按「可以」。國定假日比平日、假日優先，所以要另外設。
  3. 時段：假日套用 13:30–21:00。不想先填時間，就留著「可以・時段未填」。
  4. 微調：4/16（五）剛好請假，晚上可以。點那一天，再按上方滑鈕的「可以」；之後點日期會依序換成可以 → 不行 → 未填。
  5. 想單獨改某天的時間，長按那一天（電腦按右鍵）。
  6. 完成：摘要會列出她可以、不行的日子和通常時段，確認後去看合併結果。

案例 3 · 管理員代填

幫不太用手機的王伯伯先填好

角色：管理員。用到：「管理成員」→ 名字旁的「代填」

  1. 管理員登入後，在成員清單按王伯伯旁邊的「代填」。不用輸入他的密碼。
  2. 畫面上方會出現黃色提示「管理員模式」，照四個步驟幫他填。
  3. 他的按鈕會顯示「管理員已預填」，合併結果也會把他算進去。
  4. 之後王伯伯自己點進來，還是會看到「第一次進入」，可以設密碼，也能直接改管理員填的內容。

案例 4 · 看結果、定日子

大家填完，挑出聚會日

角色：任何人。用到：「合併結果」

  1. 點最右邊的「合併結果」，深綠色大卡寫著「最快可以約」的日期和共同時段。
  2. 月曆上深綠色格子是所有人都可以，格子裡直接寫共同時段。
  3. 每格底下的小圓點代表每個人：綠是可以、紅是不行、灰是還沒填。
  4. 點任一天，會列出每個人當天的狀態和時段，方便找出是誰卡住、要不要喬一下。

案例 5 · 下一次活動

同一個網站，換季重來

角色：管理員

  1. 在「活動設定」改名稱和日期範圍，例如「夏季讀書會」2027-07 到 2027-09。
  2. 舊的資料不會被刪掉，只是不在新範圍裡就不會顯示。
  3. 想讓大家重新填，請成員在完成頁按「全部重來」，或由管理員刪除再重新加入成員。
  4. 想同時辦好幾個活動，就再按一次一鍵部署，用不同的專案名稱，每個活動各有自己的網址和資料庫。

進階

想改外觀或功能

一鍵部署會在你的 GitHub 建一份程式，改完推上去，Cloudflare 會自動重新部署。

git clone https://github.com/你的帳號/你的專案
# 改網頁：team-cal.html；改說明頁：guide.html；改後端：src/api.js
python3 build.py      # 把 HTML 包進 src/page.js、src/guide.js
git commit -am "改了什麼" && git push   # 推上去就會自動部署
常見問題

開始之前你可能想知道

資料存在哪裡？

存在你自己 Cloudflare 帳號裡的 D1 資料庫，只有你看得到後台。網站本身任何拿到網址的人都能打開和填寫。

要付錢嗎？

Cloudflare Workers 和 D1 都有免費方案，十幾二十人的揪團通常用不完。實際額度以 Cloudflare 的公告為準。

成員密碼安全嗎？

成員密碼是用來防止別人不小心改到你的日曆，不是銀行等級的保護，請不要用重要帳號的密碼。管理員密碼只存在 Cloudflare 的密碼變數裡。

部署時忘了填管理員密碼怎麼辦？

到 Cloudflare 後台 → 你的 Worker → 設定 → 變數和密碼，新增密碼類型的 ADMIN_PASSWORD，儲存後重新整理網站就能登入。

一鍵部署按鈕打不開？

按鈕只支援公開的 GitHub 或 GitLab 專案。如果你是從自己的私人專案部署，請先把專案設成公開，或在電腦上執行 npx wrangler deploy。
